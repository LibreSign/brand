# Color system

## Brand colors

| Role | HEX |
|---|---|
| Primary Teal | `#184c4e` |
| Primary Hover | `#0f3739` |
| Primary Dark | `#0b5f55` |
| Dark Surface | `#123c40` |
| Secondary Cyan | `#00a3be` |
| Light Surface | `#f7fafc` |
| Light Text | `#f5f5f5` |
| Dark Text | `#2d3748` |

These values define the current LibreSign digital brand system.

Semantic colors for success, warning, focus, and errors are implementation tokens and must be validated for accessibility in context.

## Rule

Do not infer logo colors from arbitrary UI tokens. Official artwork comes from the canonical SVG master.

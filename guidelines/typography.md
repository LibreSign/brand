# Typography

The historical LibreSign brand manual specifies **Catamaran** as the supporting type family and demonstrates multiple weights.

## License

The upstream Catamaran family in Google Fonts is licensed under the **SIL Open Font License 1.1**.

Implications:
- original font files may be bundled and embedded with the manual;
- font files must retain OFL licensing and copyright metadata;
- font files must **not** inherit this repository's CC BY-SA license;
- the manual may embed the font without changing the manual's own content license.

## Repository policy

Prefer a verified upstream Catamaran release over an undocumented copied font binary. If font files are committed, place them under `source/fonts/catamaran/` and include their upstream licensing metadata.

## Weights

The legacy manual visually demonstrates several Catamaran weights. The migrated manual should name the exact weights used for headings/body/UI examples instead of displaying an unlabeled specimen only.

## Fallbacks

The final web/manual fallback stack should be documented after checking current website typography and rendering metrics.

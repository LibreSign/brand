# Visual identity

## Canonical artwork

The canonical logo master is:

`source/artwork/libresign-logo.svg`

All public derivatives should be generated from this master.

## Current digital palette

The current primary digital color is `#184c4e`.

The artwork itself defines the colors of the official mark. Do not recolor the logo by substituting UI tokens.

## Clear space

Maintain sufficient clear space around the logo so it remains visually independent from text, borders, and other marks.

## Minimum size

Use the complete mark only when the wordmark remains legible. For small-format usage, use an approved icon asset rather than shrinking the complete mark beyond legibility.

## Rules

Do not:
- distort proportions;
- alter the geometry;
- recolor the mark outside approved variants;
- add shadows, outlines, gradients, or decorative effects;
- rearrange components;
- create alternate “official” files outside the canonical source.

Derived PNG/PDF files are generated from the canonical SVG by CI.

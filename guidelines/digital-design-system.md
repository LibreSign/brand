# Digital design system relationship

This document resolves the relationship between the 2021 LibreSign visual-identity manual and the current website.

## Decision

The brand system has distinct layers.

### Core identity

Stable unless explicitly redesigned:
- official LibreSign naming;
- logo and icon geometry;
- documented approved logo variants;
- clear-space and minimum-size rules;
- trademark usage.

### Historical palette

The 2021 manual documents gray `#49494a` and green `#2b936b` as primary identity colors, with `#184c4e` among the supporting colors.

These values remain the historical reference for legacy artwork and should not be silently rewritten.

### Current digital palette

The current website promotes `#184c4e` to **primary digital color** and defines additional UI tokens such as hover, dark-surface, focus, semantic success/warning/error, and secondary colors.

That is an intentional digital-system layer. It does not retroactively change the color values embedded in historical logo artwork.

### Historical typography

The 2021 manual specifies **Catamaran**.

### Current digital typography

The current website uses **Montserrat** as its primary UI typeface. Montserrat is therefore the official current web/UI typography unless the website design system is deliberately changed.

Catamaran remains a documented historical/editorial typeface, not a requirement for current UI.

## Governance rule

A digital redesign may evolve UI typography and semantic tokens without constituting a logo redesign. Changes to logo geometry, approved core marks, or official naming require explicit brand-system review and a major brand release.

The public manual must label core, historical, and current-digital rules clearly.

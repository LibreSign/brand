# Digital design system

The digital design system is the implementation layer of the LibreSign brand.

## Typography

- Primary UI typeface: Montserrat

## Primary token

- Primary: `#184c4e`

## Supporting tokens

The current site defines additional hover, dark-surface, focus, semantic, and accessibility colors.

## Implementation rule

UI tokens may evolve through the design system without changing the logo contract. Changes to the logo, official name, or canonical artwork require an explicit brand-system change.

Accessibility is mandatory for interactive and textual uses.

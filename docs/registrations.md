This file records official LibreSign registration identifiers that are useful for public reference. It intentionally keeps trademark and software registrations separate because they protect different things.

## Publication rule

Only stable public registration identifiers needed to identify the record belong in this repository. Filing-system reference numbers, payment references, private account identifiers, and other administrative data should not be published unless there is a clear public need.

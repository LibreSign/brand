# Changelog

Semantic versioning is used for tagged brand-system releases.

- PATCH: corrections without changing intended use.
- MINOR: compatible additions.
- MAJOR: changes that invalidate prior usage.

## Unreleased

- Canonical brand repository established.
- SPDX/REUSE compliance enabled.
- Canonical SVG artwork added.
- Reproducible PNG/PDF generation added.
- Typst manual added.
- Current naming, pronunciation, colors, typography, accessibility, and digital design-system contract defined.
- Brand purpose, audience, free-software culture, cooperative context, messaging, and plain-English voice defined.
- Source-derived clear-space diagram and correct/incorrect-use examples added.
- Approved primary, white, and one-color logo variants documented.
- Linked contents, PDF bookmarks, semantic headings, and page-top navigation added.
- PDF/UA-1 validation added with veraPDF.
- GitHub Actions dependency management and immutable SHA pinning added.
- DCO enforcement aligned with the repository DCO GitHub App.
- The previous proprietary/manual-only workflow has been replaced by the version-controlled open brand system.
